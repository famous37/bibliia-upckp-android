# Біблія УПЦ КП

Українська Біблія в перекладі Патріарха Київського і всієї Руси-України Філарета. Розробник застосунку — Василь Шлемко.

## Видання

50 книг Старого Завіту та 27 книг Нового Завіту, включно з Псалмом 151. Збережено примітки, паралельні місця, чотири текстові додатки й шість сторінок покажчика старозавітних читань на церковних службах. Текст, пошук і додатки працюють офлайн.

## Читання

- У вкладці **Книги** оберіть Завіт, книгу та главу. Книгу також можна знайти за короткою назвою.
- **Пошук** приймає слово, фразу або посилання, наприклад `Ін 3:16`, `Пс 50` чи `Мф 5:9`.
- Торкніться номера глави над текстом для переходу до іншої глави чи вірша.
- Торкніться вірша, щоб зберегти його, скопіювати або надіслати. Останнє місце читання відновлюється під час запуску.
- Кнопка **Аа** змінює тему, шрифт, кегль і міжрядковий інтервал.

## Android

Версія 2.0.1. Мінімальна версія Android 8.0 (API 26). Цільова версія Android 17 (API 37). Пакет `ua.shlemko.bibliia` встановлюється поряд зі старим застосунком. Закладки попереднього видання зберігаються в ньому.

## Збирання

Відкрийте проєкт у Android Studio з JDK 17, платформою Android SDK 37.0 та Build Tools 36.0.0. Для локальної збірки:

```sh
python3 tools/check_edition.py
./gradlew :app:assembleDebug
```

Пакет для тестування з’явиться в `app/build/outputs/apk/debug/`. Для релізу виконайте `./gradlew :app:lintRelease :app:assembleRelease` і підпишіть APK ключем проєкту через Android Studio або apksigner.

Тексти й ілюстрації вже включені. Повторний імпорт з початкового APK:

```sh
python3 tools/import_edition.py 'Bible(UOC-KP).apk' app/src/main/assets/reader
python3 tools/check_edition.py
```
